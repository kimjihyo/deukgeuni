# 파워빌딩 근력 블록 (6주, 테스트 포함)

3대 e1RM을 올리고 블록 끝에 1RM 테스트. 테스트를 안 하면 W5에서 끝내고 근비대 블록으로.
설계 근거: DUP [Moesgaard 2022](../../evidence/periodization.md#moesgaard-2022-주기화-메타분석), 탑세트+백오프 [RTS](../../evidence/programs.md#rts-reactive-training-systems), 테이퍼 [Travis 2020](../../evidence/tapering-peaking.md#travis-2020-파워리프팅-테이퍼링피킹).

## 주간 구성 (주 5일 예)

| 날 | 내용 |
| --- | --- |
| D1 | 스쿼트 헤비 + 벤치 볼륨 + 하체·팔 보조 |
| D2 | 데드 헤비 + 등·팔 보조 |
| D3 | 벤치 헤비 + 어깨 보조 (평일이면 3종목) |
| D4 | 스쿼트 볼륨 + 벤치 가볍게 + 로우 + 햄스트링 |
| D5 | 약점 부위 보조 (일정이 밀리면 가장 먼저 뺌) |

## 메인 리프트 진행

탑세트 `최소횟수+@RPE` + 백오프(탑세트 대비 −%). 무게는 매주 실제 탑세트 e1RM으로 다시 계산.

| 운동 | W1 | W2 | W3 | W4 | W5 | W6 테이퍼 |
| --- | --- | --- | --- | --- | --- | --- |
| 스쿼트 헤비 | 4+@8 + 4×4 −8% | 3+@8 + 4×3 −8% | 3+@8.5 + 4×3 −7% | 2+@8.5 + 3×2 −8% | 1@9 + 2×2 −8% | 1@7 + 2×2 |
| 데드 헤비 | 4+@8 + 3×4 −8% | 3+@8 + 3×3 −8% | 3+@8.5 + 3×3 −8% | 2+@8.5 + 2×2 −8% | 1@9 + 2×2 (마지막 헤비) | 휴식 |
| 벤치 헤비 | 4+@8 + 3–4×4 −7% | 3+@8 + 3–4×3 −7% | 3+@8.5 + 3–4×3 −7% | 2+@8.5 + 3×2 −7% | 1@9 + 3×2 | 1@7 + 2×2 |
| 벤치 볼륨 | 4×6@8 | 4×5@8 | 4×5@8.5 | 3×4@8 | 3×3@7.5 | 2×5@6.5 |
| 스쿼트 볼륨 | 4×6@7.5 | 5×5@7.5 | 5×4@8 | 4×3@8 | 3×3@7.5 | 1@6 |
| 벤치 가볍게 | 3×6@7 | 3×5@7 | 3×5@7.5 | 3×3@7.5 | 2×3@7 | 1@6 |

테스트는 W6 주말. 시기 선택은 `docs/principles/peaking-testing.md`.

## 보조운동

- W1–W3: 운동당 3세트, RPE 8 → W3 8.5. 약점 부위 운동은 4–5세트
- W4: 세트 −1, RPE 8 / W5: 2세트 / W6: 2세트 RPE 7
- 이중 진행 (`docs/principles/progression.md`)

## 조정 포인트

- 주 4일: D5 삭제, 약점 부위 세트를 D1·D2에 1–2세트씩 분산
- 주 3일: D1(스쿼트 헤비+벤치 볼륨), D2(데드), D3(벤치 헤비+스쿼트 볼륨 가볍게)
- 스쿼트가 정체면 스쿼트 볼륨 날 세트 +1, 벤치가 정체면 벤치 볼륨 RPE +0.5
