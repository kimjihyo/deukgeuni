# 파워빌딩 근비대 블록 (4–6주)

근력 블록 사이에 근육량을 쌓는다. 메인 리프트는 기술·근력을 유지하는 수준으로, 보조운동 볼륨을 늘린다.
설계 근거: 근비대는 볼륨에 비례해 이득이 이어짐 [Pelland 2026](../../evidence/volume-frequency.md#pelland-2026-볼륨빈도-용량-반응), 보조운동 1–2 RIR [Refalo 2024](../../evidence/proximity-to-failure.md#refalo-2024-실패-vs-12-rir-근비대).

## 주간 구성 (주 5일 예)

| 날 | 내용 |
| --- | --- |
| D1 | 스쿼트 5–6회 + 하체 보조 (레그프레스, 레그컬, 종아리) |
| D2 | 데드 또는 RDL + 등 (수직·수평 당기기 각 1) + 이두 |
| D3 | 벤치 5–8회 + 어깨 (OHP 또는 인클라인, 레터럴) + 삼두 |
| D4 | 스쿼트 변형 또는 레그프레스 + 벤치 변형 + 등 |
| D5 | 약점 부위 + 팔 |

## 메인 리프트

| 주 | 처방 |
| --- | --- |
| W1 | 4×6 @7 (블록 시작 e1RM의 약 75%) |
| W2 | 4×6 @7.5 |
| W3 | 4×5 @8 |
| W4 | 5×5 @8 |
| (W5–6) | 탑 5+ @8 + 3×5 −8%, 근력 블록 준비 |

메인 리프트는 주 2회(벤치는 2–3회) 유지. 근력이 떨어지지 않는 선에서 볼륨 기여.

## 보조운동

- 부위별 주간 세트: 블록 시작 때 `wl.py volume --weeks 4`로 현재 수준 확인 → 약점 부위 +2–4세트, 나머지 유지 또는 +2
- 반복: 복합 6–12, 고립 10–20. RPE 8 → 마지막 주 9–9.5 (고립은 마지막 세트 실패 허용)
- 이중 진행
- 같은 종목을 블록 내내 유지해서 진행을 잴 수 있게 한다

## 블록 끝

- 마지막 주 또는 다음 블록 첫 주에 피로 신호를 확인하고 필요하면 디로드 (`docs/principles/fatigue-deload.md`)
- 회고: 부위별 세트 변화, 보조운동 무게·횟수 기록 경신, 3대 e1RM 유지 여부
