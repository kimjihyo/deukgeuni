## 카드 형식

```markdown
## 저자 연도 짧은 제목
유형 / 대상(초보·중급·숙련·혼합) / DOI 또는 URL
- **처방**: 바로 적용할 수 있는 문장
- **한계**: 대상·설계·표본의 제약
```

## 카드 추가 규칙

1. DOI·URL을 실제로 확인한 뒤 추가 (기억으로 인용 금지)
2. 원문을 길게 옮기지 말고 요약
3. 처방은 "그래서 무엇을 하라"로, 한계는 솔직하게
4. 주제에 맞는 파일에 넣고 위 표 갱신. 새 주제면 새 파일

## 추가 예정 (보디빌딩 확장)

근비대 종목 선택(스트레칭 구간), 세트 간 휴식, 디로드, 에너지 섭취와 근비대 등.
