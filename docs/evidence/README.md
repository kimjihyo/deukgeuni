# 근거 카드

코칭 판단의 근거는 **이 폴더의 카드에서만** 인용한다. 카드가 없으면 "근거 카드 없음(경험칙)"이라고 밝힌다.

**외부 링크를 두지 않는다.** 인터넷 자료는 언제 사라질지 모른다. 카드는 그 자체로 완결되어야 한다: 필요한 내용(무엇을 연구했고 무엇을 찾았는지, 그래서 어떻게 처방하는지, 한계)을 카드 본문에 적는다. 출처는 찾아갈 수 있도록 서지 정보와 DOI·PMID 같은 **식별자를 일반 텍스트로만** 남긴다 (하이퍼링크 아님).

## 카드 형식

```markdown
## 저자 연도 짧은 제목
유형 / 대상(초보·중급·숙련·혼합) / 출처 식별자: DOI 10.xxxx (저널) — 링크 없이 텍스트로
- **내용**: 대상·방법·주요 결과 (원문을 안 봐도 이해되게, 수치 포함)
- **처방**: 바로 적용할 수 있는 문장
- **한계**: 대상·설계·표본의 제약
```

## 카드 추가 규칙

1. 원문(또는 초록)을 실제로 확인한 뒤 추가 (기억으로 인용 금지). 초록만 봤으면 한계에 "원문 본문 미확인"
2. 필요한 내용은 카드 안에 요약해 넣는다. 원문을 길게 그대로 옮기지는 않는다 (저작권)
3. URL·하이퍼링크는 넣지 않는다. 식별자(DOI, PMID, ISBN)와 서지 정보만 텍스트로
4. 처방은 "그래서 무엇을 하라"로, 한계는 솔직하게
5. 주제에 맞는 파일에 넣고 위 표 갱신. 새 주제면 새 파일

## 추가 예정 (보디빌딩 확장)

근비대 종목 선택(스트레칭 구간), 세트 간 휴식, 디로드, 에너지 섭취와 근비대 등.

## 보강 필요

기존 카드는 결과를 **처방** 항목 안에 함께 적은 형식이다. 원문을 다시 확인해 **내용** 항목(대상·방법·주요 수치)을 따로 채운다. 확인 전에는 지금 적힌 범위만 인용한다.
