# 자동조절 · RPE

RPE·RIR 척도와 자동조절(RPE 기반 부하)의 근거.

## Zourdos 2016 RIR 기반 RPE 척도
척도 검증 / 혼합 / https://doi.org/10.1519/JSC.0000000000001049
- **처방**: RPE = 10 − RIR로 처방·기록. 바 속도 저하와 RPE 상승이 대응 → 일일 부하 조절 도구.
- **한계**: 스쿼트만, 29명. 훈련 효과 비교 연구 아님.

## Helms 2016 RIR 기반 RPE 적용법
리뷰 / 혼합 / https://doi.org/10.1519/SSC.0000000000000218
- **처방**: 세트마다 목표 RPE에 맞춰 무게 조정. 메인 리프트 탑세트는 RPE로 처방.
- **한계**: 실무 안내서.

## Helms 2018 RPE vs %1RM 부하
RCT / 숙련 / https://doi.org/10.3389/fphys.2018.00247
- **처방**: 8주 DUP에서 RPE 부하가 %1RM만큼 효과적, 1RM에서 작은 우위 가능성. 탑세트는 RPE, %는 시작 무게 참고.
- **한계**: 21명 남성, 8주, 스쿼트·벤치만. 유의차 없음.

## 2025 자동조절 네트워크 메타분석
메타분석 / 혼합 / https://doi.org/10.1016/j.jesf.2025.07.006 (J Exerc Sci Fit)
- **처방**: APRE·속도 기반·RPE 기반 모두 고정 %1RM보다 최대근력 향상에 효과적 → 메인 리프트는 RPE 자동조절.
- **한계**: 프로토콜 이질성 큼, 순위 불확실성 큼.
