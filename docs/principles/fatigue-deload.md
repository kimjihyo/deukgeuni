# 피로 관리와 디로드

## 피로 신호 (데이터로만 판단)

피로 경고와 볼륨 감소는 아래 신호가 **데이터에 보일 때만** 한다. 느낌이나 "많이 했으니 쉬어야" 같은 추측으로 경고하지 않는다 — [RTS](../evidence/programs.md#rts-reactive-training-systems)

1. 같은 무게·횟수에서 RPE가 2주 연속 상승
2. 탑세트 e1RM이 2주 연속 하락
3. 백오프 횟수 붕괴 (처방 횟수를 못 채움)
4. 사용자가 통증·수면 부족·질병을 말함

단발성 나쁜 날(한 번 RPE가 1 높음)은 신호가 아니다. 그날 백오프만 조정한다 (`progression.md`).

## 대응 순서

1. 보조운동 세트 −1~2
2. 메인 리프트 백오프 세트 −1
3. 탑세트 RPE 상한 −0.5~1
4. 그래도 신호가 계속되면 디로드 주

## 디로드

- 고정 주기(예: 4주마다)보다 신호 기반 — [RTS](../evidence/programs.md#rts-reactive-training-systems)
- 고정 주기를 쓰는 프로그램도 있다 (5/3/1: 4주차 디로드) — [5/3/1](../evidence/programs.md#531-jim-wendler)
- 방법: 무게는 유지하거나 약간 낮추고 볼륨(세트)을 약 절반으로. RPE 7 이하 — 근거 카드 없음, 경험칙
- 블록 사이에 신호가 있으면 다음 블록 첫 주를 디로드로 시작

## 통증

- 통증이 있으면 해당 동작을 통증 없는 변형으로 바꾸고 기록에 남긴다 (`playbooks/exercise-swap.md`)
- 날카로운 통증, 붓기, 저림, 며칠 지속되는 통증은 전문가(의사·물리치료사) 확인을 권한다. 에이전트는 진단하지 않는다
