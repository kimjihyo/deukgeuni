# 종목 선택

## 분류

- **대회 종목**: 스쿼트, 벤치프레스, 데드리프트 (파워리프팅 규정 동작)
- **변형**: 대회 종목의 변형 (정지 벤치, 정지 스쿼트, 데피싯 데드 등). 운동 사전에 별개 운동으로 등록
- **보조**: 근비대·약점 보완용 (로우, 풀업, 레터럴 레이즈, 컬 등)

## 고르는 기준

1. **목표에 맞는가** — 근력 목표 리프트는 그 리프트 자체를 자주. 근비대는 부위별 세트를 채울 수 있는 종목
2. **사용자가 실제로 할 수 있는가** — 기구, 셋업 편의, 통증 여부. 셋업이 불편하면 꾸준히 못 한다 → 비슷한 근육을 쓰는 더 편한 종목으로
3. **진행을 잴 수 있는가** — 증량 단위가 너무 크거나 기구마다 무게가 다르면 같은 기구를 고정
4. **피로 대비 자극** — 메인 리프트와 겹치는 피로(허리 등)가 큰 보조는 줄인다 (예: 허리가 불편한 주에는 RDL → 레그컬)

근거 카드 없음 — 위 기준은 경험칙. 근비대용 종목 선택(스트레칭 구간 강조 등) 근거는 보디빌딩 지식 확장 때 추가 예정 (`docs/goals/bodybuilding.md`).

## 패턴 균형 (주간)

| 패턴 | 예 |
| --- | --- |
| 스쿼트 | 스쿼트, 레그프레스 |
| 힌지 | 데드리프트, RDL, 레그컬(무릎 굴곡 보완) |
| 수평밀기 | 벤치, 인클라인 프레스 |
| 수직밀기 | OHP |
| 수평당기기 | 로우류 |
| 수직당기기 | 풀업, 하이 로우 |
| 고립 | 레터럴 레이즈, 리어 델트, 팔 |

당기기(수평+수직) 세트가 밀기 세트보다 적지 않게 — 경험칙.

## 기구 기록 규칙

- 덤벨·편측: 한쪽 무게
- 양쪽에 원판을 따로 끼우는 머신(하이 로우 등): 한쪽 원판 무게 (사용자와 합의한 규칙을 프로필에 적는다)
- 기구마다 무게가 다른 머신은 프로필에 어느 기구인지 적는다
