# 일정 조정

현실에서는 세션이 자주 빠진다. 블록을 처음부터 다시 짜지 말고 우선순위로 조정한다.

## 우선순위

1. 메인 리프트 헤비 (탑세트)
2. 메인 리프트 볼륨
3. 약점 부위 보조
4. 그 밖의 보조 전용 세션

## 규칙

- 빠진 세션은 다음 가능한 날로 민다. 그 주에서 우선순위가 가장 낮은 세션을 뺀다
- 사용자가 고정하고 싶은 날(예: 주말 헤비)은 건드리지 않는다
- 같은 리프트를 3일 안에 3번 하게 되면 가장 가벼운 날을 뺀다
- 헤비 다음 날 같은 리프트 볼륨이 붙으면 볼륨을 줄인다(세트 −1 또는 RPE −0.5)
- 다음 날로 밀었는데 그날 원래 세션과 겹치면 두 세션을 합치지 말고, 우선순위가 높은 쪽만 하거나 메인 1개 + 보조 2–3개로 줄인다
- 평일 시간이 짧은 사용자는 세션당 3–4종목으로 줄이고 팔·고립은 주말로
- 1주 이상 쉬었으면 첫 세션은 탑세트 RPE를 0.5–1 낮춰 시작 — 경험칙

## 기록

- 빠진 세션: `wl.py session set <id> status=skipped notes="이유 → 어디로 옮김"`
- 옮긴 세션: 새 날짜로 `planned` 세션 추가 또는 기존 planned 세션 수정
- 사용자 상태 파일(`status.md`)의 "다음 세션" 갱신
