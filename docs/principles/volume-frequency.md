# 볼륨과 빈도

## 세트 세기

- **작업 세트** = 워밍업 제외, 1회 이상 수행한 세트
- 근육별 주간 세트 = 주동근 1.0 + 보조근 0.5 (운동 사전의 `primary_muscles`, `secondary_muscles`) — [Pelland 2026](../evidence/volume-frequency.md#pelland-2026-볼륨빈도-용량-반응)
- 계산: `wl.py volume --weeks 4` (기본 최근 7일 단위), 강한 세트만 보려면 `--min-rpe 7`

## 볼륨

- **근비대**: 주간 세트를 늘릴수록 이득이 이어진다 (수확체감은 있음) — [Pelland 2026](../evidence/volume-frequency.md#pelland-2026-볼륨빈도-용량-반응)
- **근력**: 볼륨의 수확체감이 더 빠르다 → 메인 리프트는 세트를 무작정 늘리지 말고 질(RPE·속도)을 유지
- 시작점: 부위당 주 10세트 안팎에서 시작, 진행이 멈추고 회복이 충분하면 2–4세트씩 늘린다 — 근거 카드 없음, 경험칙. 정확한 임계값은 원문 확인 필요
- 볼륨을 늘릴 때는 한 번에 한 부위씩, 약점 부위부터

## 빈도

- 주간 볼륨이 같으면 빈도 자체의 효과는 작다. 빈도의 이점은 대부분 더 많은 볼륨을 소화하게 해주는 데서 온다 — [Grgic 2018](../evidence/volume-frequency.md#grgic-2018-빈도와-근력)
- 근력(기술 연습)에는 빈도가 일관된 효과 → 메인 리프트는 주 2–3회 — [Pelland 2026](../evidence/volume-frequency.md#pelland-2026-볼륨빈도-용량-반응)
- 벤치는 주 3회까지 무난. 스쿼트·데드는 피로가 커서 데드는 주 1회 헤비 + 변형으로 보충하는 경우가 많다 — 데드 주 1회는 경험칙
- 한 세션에 같은 부위 세트가 너무 많으면(대략 8–10세트 이상) 다른 날로 나눈다 — 경험칙
