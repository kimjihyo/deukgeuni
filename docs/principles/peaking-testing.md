# 피킹과 1RM 테스트

## 블록 끝 구조

축적(4–6회) → 강화(2–3회) → 싱글(@9) → 테이퍼 → 테스트

## 테이퍼

- 1–2주. 볼륨 30–50% 감소, 강도(≥85%)는 유지하거나 소폭만 낮춤 — [Travis 2020](../evidence/tapering-peaking.md#travis-2020-파워리프팅-테이퍼링피킹)
- 테스트 2–7일 전은 쉬어도 되지만 7일을 넘기면 근력이 떨어진다
- 데드는 마지막 1–2주에 빼도 된다 (마지막 데드 헤비는 테스트 약 2주 전)
- 보조운동은 세트를 줄이고 RPE 7 정도로

## 테스트 당일

- 순서: 스쿼트 → 벤치 → 데드
- 워밍업: 빈 바 → 40–50% → 60% → 70% → 80% → 85–88% 싱글 (세트 간 휴식 점점 늘림) — 경험칙
- 시기: 1차 약 92%, 2차 약 97%, 3차는 2차 RPE로 결정 — 경험칙, 근거 카드 없음
  - 2차 @8 이하 → +5–7.5kg (최소 증량 단위가 5kg면 +5)
  - 2차 @9 → +2.5–5kg
  - 2차 @9.5 이상 → 시도하지 않거나 최소 증량
- 시기 무게는 테스트 약 1주 전 마지막 헤비 기록(e1RM)으로 확정
- 장비(벨트, 스트랩, 슬리브)는 평소 훈련과 같게. 테스트 때 처음 쓰는 장비는 피한다
- 대회가 아니라 개인 테스트면 규정(정지 벤치 등)을 따를지 사용자에게 미리 확인

## 실패 기록

실패 시기는 `reps=0`, RPE 비움, note에 이유(예: "락아웃 직전 그립 풀림"). e1RM 계산에서 자동 제외된다.
