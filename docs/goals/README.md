# 목표별 문서

사용자 프로필의 `goal`에 맞는 파일을 읽는다. 공통 원칙(`docs/principles/`)은 모든 목표에 적용된다.

| goal | 파일 | 상태 |
| --- | --- | --- |
| `powerbuilding` | [powerbuilding.md](powerbuilding.md) | 완성 (기본값) |
| `powerlifting` | [powerlifting.md](powerlifting.md) | 준비 중 — 파워빌딩 + 피킹 원칙으로 대체 |
| `bodybuilding` | [bodybuilding.md](bodybuilding.md) | 준비 중 — 파워빌딩의 보조운동·볼륨 원칙으로 대체 |

새 목표를 추가하려면: `docs/goals/<goal>.md`, `docs/programs/<goal>/` 템플릿, 필요한 근거 카드를 추가하고 이 표를 갱신한다.
