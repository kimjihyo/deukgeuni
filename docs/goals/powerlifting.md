# 파워리프팅

> **준비 중.** 지금은 파워빌딩 문서와 공통 원칙으로 코칭한다. 파워리프팅 전용 내용은 이 파일에 채워 넣는다.

## 파워빌딩과 다른 점 (채울 내용)

- 목표: 시합(또는 테스트) 날 3대 합계 최대화. 근비대는 수단
- 시합 규정 반영: 스쿼트 깊이, 벤치 정지(press 콜), 데드 락아웃, 장비(RAW/싱글플라이)
- 특이성 높은 변형 위주 보조, 고립 운동 비중 낮음
- 체급 관리, DOTS·IPF GL 점수
- 시합 준비: 시기 선택 전략, 시합일 워밍업 타임라인, 체중 측정 전후

지금 바로 쓸 수 있는 공통 문서: `docs/principles/peaking-testing.md`, `docs/principles/progression.md`.
