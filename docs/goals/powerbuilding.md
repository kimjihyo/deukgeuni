# 파워빌딩

**목표**: 3대(스쿼트·벤치·데드) 근력과 근육량을 함께 늘린다. 이 레포의 기본·전문 분야.

## 우선순위

1. 3대 근력 — 주 2–3회 연습, 탑세트 + 백오프로 e1RM을 끌어올린다
2. 근육량 — 보조운동으로 부위별 주간 세트를 채운다. 특히 사용자의 약점 부위
3. 지속 가능성 — 실제로 갈 수 있는 요일·시간에 맞춘다. 빠지는 날이 있다는 전제로 설계

## 주간 구조 (기본형: 주 4–5일)

DUP로 같은 주에 헤비 날과 볼륨 날을 나눈다 — [Moesgaard 2022](../evidence/periodization.md#moesgaard-2022-주기화-메타분석)

| 날 | 메인 | 보조 |
| --- | --- | --- |
| D1 | 스쿼트 헤비 (탑+백오프) + 벤치 볼륨 | 하체·팔 |
| D2 | 데드 헤비 (탑+백오프) | 등(수직·수평 당기기)·팔 |
| D3 | 벤치 헤비 (탑+백오프) | 어깨 |
| D4 | 스쿼트 볼륨 + 벤치 가볍게 | 등·햄스트링 |
| D5 (선택) | 없음 | 약점 부위 위주 근비대 |

- 메인 빈도: 스쿼트 2, 벤치 3, 데드 1 (+ 힌지 보조) — [Grgic 2018](../evidence/volume-frequency.md#grgic-2018-빈도와-근력), [Pelland 2026](../evidence/volume-frequency.md#pelland-2026-볼륨빈도-용량-반응)
- 주 3일이면: D1+D4 합침(스쿼트 헤비+벤치 볼륨), D2, D3. 볼륨은 세션당 메인 1–2 + 보조 2–3으로 압축
- 평일 시간이 짧으면 평일 세션은 3–4종목, 팔·고립은 주말로 (`docs/principles/scheduling.md`)

## 강도·볼륨 처방

| 구분 | 반복 | RPE | 근거 |
| --- | --- | --- | --- |
| 메인 탑세트 | 블록에 따라 1–5+ | 8–9 | [Helms 2018](../evidence/autoregulation.md#helms-2018-rpe-vs-1rm-부하) |
| 메인 백오프 | 2–6 | 7–8.5 | [RTS](../evidence/programs.md#rts-reactive-training-systems) |
| 메인 볼륨 날 | 4–8 | 7–8 | |
| 보조 (복합) | 6–12 | 8–9 | [Refalo 2024](../evidence/proximity-to-failure.md#refalo-2024-실패-vs-12-rir-근비대) |
| 보조 (고립) | 10–20 | 8–9.5 | [Robinson 2024](../evidence/proximity-to-failure.md#robinson-2024-실패-근접도-메타회귀) |

- 부위별 주간 세트: 약 10세트에서 시작, `wl.py volume`으로 확인하며 조정 (`docs/principles/volume-frequency.md`)
- 근력 블록에서는 보조 볼륨을 조금 줄이고, 근비대 블록에서는 메인을 유지 강도로 두고 보조를 늘린다

## 블록 순환

| 블록 | 기간 | 메인 리프트 | 보조운동 |
| --- | --- | --- | --- |
| 근비대 중심 | 4–6주 | 5–8회 @7–8, 유지·완만한 증량 | 세트 많이, RPE 8–9.5 |
| 근력 중심 | 4–6주 | 4+ → 1 @8–9, e1RM 진행 | 세트 보통, RPE 8–9 |
| 피킹·테스트 (선택) | 1–2주 | 싱글 → 테이퍼 → 테스트 | 최소 |

- 템플릿: [`docs/programs/powerbuilding/`](../programs/powerbuilding/)
- 근력 블록 끝에 테스트를 할지는 사용자 선택. 테스트를 안 하면 테이퍼도 생략하고 다음 블록으로
- 블록 전환 때 피로 신호가 있으면 첫 주를 디로드로 (`docs/principles/fatigue-deload.md`)

## 진행 지표

- 3대 e1RM (`wl.py e1rm`)과 합계
- 부위별 주간 세트 (`wl.py volume --weeks 4`)
- 보조운동 이중 진행 달성 여부 (같은 무게에서 횟수 상단 도달)
- (선택) 체중·둘레 — 아직 데이터 모델에 없음. 보디빌딩 확장 때 추가 예정
