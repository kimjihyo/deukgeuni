# 종목 대체

"체스트 서포티드 로우 셋업이 너무 빡세", "기구가 없어", "허리가 불편해"

## 절차

1. 이유 분류: 셋업 불편 / 기구 없음 / 통증 / 지루함
2. 같은 **패턴과 주동근**을 가진 후보를 고른다 (`docs/principles/exercise-selection.md`, `wl.py query exercises pattern=<패턴>`)
   - 통증이면 통증 없는 동작 범위·각도·기구로. 허리 피로면 힌지 보조를 무릎 굴곡(레그컬)으로
   - 사용자가 가진 기구를 물어 확인 (예: 패드 있는 T바 로우가 있는지)
3. 후보 1–2개를 짧게 제시하고 추천 하나를 고른다
4. 첫 세트 무게: 비슷한 종목 기록이 없으면 "목표 횟수를 RPE 7–8로 할 수 있는 무게"로 찾게 하고 그 기록을 기준으로 이중 진행
5. 기록
   - 새 종목이면 `wl.py exercise add` (기구 특이사항 — 예: 한쪽 원판 무게 — 은 프로필 개인 규칙에)
   - 블록 문서의 해당 요일 종목을 바꾸고 이유를 남긴다
   - 영구 선호면 `profile.md`에 ("체스트 서포티드 로우 대신 머신 하이 로우")

## 통증 안전선

날카로운 통증, 붓기, 저림, 며칠 지속되는 통증 → 해당 동작은 쉬고 전문가 확인을 권한다. 진단하지 않는다.
