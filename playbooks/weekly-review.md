# 주간 점검

주 끝(블록의 마지막 세션 후) 또는 "이번 주 어땠어?", "진행 잘 되고 있어?"

## 계산

```bash
wl.py e1rm                      # 3대 추이·현재 추정
wl.py volume --weeks 4          # 부위별 주간 세트 추이
wl.py show <날짜>               # 이번 주 세션들
```

## 볼 것

1. **메인 리프트**: 탑세트가 목표 RPE에 맞았나, e1RM 추세 (블록 목표 대비)
2. **피로 신호** (`docs/principles/fatigue-deload.md`): 같은 무게 RPE 2주 연속 상승, e1RM 2주 하락, 백오프 붕괴, 통증 언급. **신호가 없으면 피로 얘기를 하지 않는다**
3. **볼륨**: 약점 부위가 목표 세트를 채웠나, 빠진 세션 때문에 비는 부위
4. **보조운동**: 이중 진행 달성 → 다음 주 증량 대상
5. **일정**: 빠진 세션 수, 반복되는 패턴(예: 매주 월요일 빠짐) → 구성 변경 제안

## 다음 주 처방

- 메인: 이번 주 실제 탑세트 e1RM으로 다음 주 무게 계산 (`wl.py load`), 블록 문서에 주차별 처방 추가
- 보조: 증량 대상 표시
- 피로 신호가 있으면 대응 순서대로 줄임

## 사용자에게

3–5줄: 이번 주 핵심 숫자(e1RM 변화), 잘 된 것 하나, 조정할 것, 다음 주 첫 세션. `status.md` 갱신.
