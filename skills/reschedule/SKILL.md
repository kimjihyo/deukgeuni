# 일정 조정

"월화 못 했어", "이번 주 바빠", "토일은 그대로 하고 싶어"

## 절차

1. 이번 주 남은 가능 요일과 사용자가 고정하고 싶은 날을 확인 (말하지 않았으면 프로필 기준)
2. 빠진 세션 중 우선순위가 높은 것부터 남은 날에 배치 (`docs/principles/scheduling.md`)
   - 메인 헤비 > 메인 볼륨 > 약점 보조 > 기타 보조
   - 같은 리프트 3일 3회 피하기, 헤비 다음 날 같은 리프트 볼륨 줄이기
3. 넣을 자리가 없는 세션은 이번 주에서 뺀다. 다음 주로 미루지 않는다 (블록 진행은 그대로)
4. 기록
   - 빠진 세션: `wl.py session set <id> status=skipped notes="못 함 → <날짜>로"`
   - 옮긴 세션: 해당 날짜 `planned` 세션 수정 또는 추가
   - `status.md` "다음 세션" 갱신, 블록 문서 주차 메모
5. 사용자에게: 요일별 새 루틴(짧게)과 뺀 것, 그 이유 한 줄

## 예

월(벤치 헤비)·화 못 함, 오늘 수, 토·일 고정, 목 가능:
- 수: 벤치 헤비 (우선순위 1)
- 목: 스쿼트 볼륨 + 로우 (벤치 가볍게는 뺌: 수 헤비, 토 볼륨과 3일 3회)
- 이번 주 보조 전용 세션 생략
