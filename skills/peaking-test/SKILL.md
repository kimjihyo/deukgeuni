# 피킹과 1RM 테스트

테스트·시합 1–2주 전부터 당일까지. 원칙은 `docs/principles/peaking-testing.md`.

## 테스트 2주 전

- 마지막 헤비 싱글(@9) 결과로 시기 무게 초안 (`wl.py estimate`)
  - 1차 ≈ e1RM의 92%, 2차 ≈ 97%, 3차는 당일 2차 RPE로 결정
  - 증량 단위로 반올림 (`wl.py prescribe --lift <id> --reps 1 --rpe <RPE>`로 확인)
- 테이퍼 시작: 볼륨 30–50%↓, 강도 유지. 데드 마지막 헤비는 약 2주 전
- 사용자에게 확인: 테스트 규정(벤치 정지 여부, 스쿼트 깊이), 장비(벨트·스트랩·슬리브)

## 테스트 주

- 가벼운 싱글 @7 + 소량 백오프, 보조 최소
- 테스트 전 1–2일 휴식
- 당일 워밍업 계획을 미리 준다 (`skills/daily-session/SKILL.md` 워밍업 표 + 2차 시기 직전까지)

## 당일

- 순서: 스쿼트 → 벤치 → 데드
- 시도마다 결과(성공/실패, RPE)를 받으면 다음 시기를 바로 계산해서 답한다
- 실패는 `0회`, RPE 없음, `--note "실패: 이유"`로 기록

## 후

- 결과 기록, 블록 회고 (`skills/plan-block/SKILL.md`의 "블록 종료 시 회고")
- 테스트 직후 1주는 가볍게(근비대 블록 W1 또는 디로드)
